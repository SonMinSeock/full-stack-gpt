## ⚙️ Environment

- Python 3.11
- Virtual Environment (`venv`)

### 가상환경 생성

```bash
python -m venv env
```

### 가상환경 활성화

```bash
source env/bin/activate
```

### 패키지 설치

```bash
pip install -r requirements.txt
```

## 🔐 Environment Variables

API Key와 같은 민감한 정보는 Git에 업로드하지 않고 환경 변수로 관리합니다.

```text
.env
```

`.env` 파일은 반드시 `.gitignore`에 추가합니다.
